## 🎯 Problem Solved

### ❓ User Question:

> "lúc chuyển qua new chat, chung ta dùng cơ chế nào để đoạn chat mới có thể lấy ngữ cảnh đã lưu trong nmem? trong system prompt phải không? hay còn cần thêm cơ chế nào tốt hơn không?"

### ❌ Previous Approach (System Prompt Only):

```
New chat starts
  ↓
System prompt: "YOU MUST call neural_memory context first!"
  ↓
Agent reads → calls neural_memory tool
  ↓
Wait for nmem response (slow, costs tokens)
  ↓
Agent uses context
```

**Problems:**
- ❌ Agent might ignore instruction
- ❌ Wastes tokens on tool calls
- ❌ Slow (wait for tool execution)
- ❌ User doesn't see context loaded
- ❌ Not guaranteed to work

### ✅ New Approach (Auto-Inject Context):

```
New chat starts (first message)
  ↓
Backend detects: isFirstMessage = true
  ↓
Auto-load context from nmem:
  - nmem context --limit 20
  - nmem today
  - nmem recall "project-scope"
  ↓
Inject as FIRST assistant message
  ↓
User sees: "🧠 Context loaded from neural memory!"
  ↓
Agent already has FULL context (no tool call needed!)
```

**Benefits:**
- ✅ **Guaranteed** - Always loads context
- ✅ **No token waste** - No tool calls needed
- ✅ **Fast** - Pre-loaded before user message
- ✅ **Transparent** - User sees what was loaded
- ✅ **Agent can't skip** - Context is already in conversation

## 🔧 Technical Implementation

### File Modified:

**`src/ipc/handlers/chat_stream_handlers.ts`** (line ~462)

Added auto-inject logic BEFORE user message insertion:

```typescript
// 🧠 AUTO-INJECT NEURAL MEMORY CONTEXT FOR NEW CHATS
const isFirstMessage = chat.messages.length === 0;

if (isFirstMessage) {
  try {
    logger.info(`[AutoLoad] First message detected - loading neural memory context`);

    const dyadAppPath = getDyadAppPath(chat.app.path);
    const projectScope = await extractProjectScope(dyadAppPath);
    const contextMessage = await loadProjectContext(projectScope);

    // Insert context as first assistant message
    await db.insert(messages).values({
      chatId: req.chatId,
      role: "assistant",
      content: contextMessage,
    });

    logger.info(`[AutoLoad] ✅ Context injected for project: ${projectScope}`);

    // Refresh chat to include the new context message
    const refreshedChat = await db.query.chats.findFirst({
      where: eq(chats.id, req.chatId),
      with: {
        messages: {
          orderBy: (messages, { asc }) => [asc(messages.createdAt)],
        },
        app: true,
      },
    });

    if (refreshedChat) {
      chat.messages = refreshedChat.messages;
    }
  } catch (error) {
    logger.warn('[AutoLoad] Failed to load context (non-critical):', error);
    // Continue without context - not critical
  }
}
```

### Error Handling:

- **Non-Critical:** If nmem fails, conversation continues without context
- **Logged:** Warning logged for debugging
- **Graceful:** No user-facing error, just missing context
