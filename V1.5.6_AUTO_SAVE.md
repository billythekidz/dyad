## 🎯 Problem Solved

### Vấn Đề Gốc:
```
Q: Why is Dyad limited to 200k tokens per conversation?
A: Claude API hard limit. When exceeded → Error!
```

**Previous Solution (v1.5.5):**
- COMPACT prompt → Reduce tokens by 88%
- Still hit limit on very long conversations
- User manually starts new chat → **loses context!** ❌

**New Solution (v1.5.6 - THIS VERSION):**
- **Auto-save conversation to neural memory** when approaching limit
- Extract project scope (git remote or path)
- Save key decisions, errors, features to nmem
- Suggest new conversation with context preserved
- **Seamless continuation!** ✅

---

## 🚀 How It Works

### Automatic Workflow:

```
User chats normally...
  ↓
Reaches 180k tokens (90% of 200k limit)
  ↓
🔔 AUTO-TRIGGER:
  "Conversation at 90% of token limit (180,000/200,000 tokens)
   Saving conversation to neural memory..."
  ↓
💾 SAVE TO NMEM:
  1. Extract project scope (git:user/repo or path:project-name)
  2. Save conversation summary (message count, features, fixes, decisions)
  3. Save top 10 key decisions → nmem remember --type decision
  4. Save top 10 errors/fixes → nmem remember --type error
  5. Index project directory → nmem index /path/to/project
  6. Consolidate memories → nmem consolidate
  ↓
✅ CONFIRM:
  "Conversation saved to neural memory!
   Project scope: git:user/repo

   You can continue in a new conversation, and context will be
   automatically loaded from neural memory."
  ↓
At 190k tokens (95% - CRITICAL):
  🚨 "Critical threshold reached (95%)

      Please start a new conversation to avoid hitting the token limit.
      Context will be automatically loaded from neural memory."
  ↓
USER STARTS NEW CONVERSATION:
  ↓
🧠 AUTO-LOAD (at first message):
  1. nmem context --limit 20 (recent context)
  2. nmem today (today's work)
  3. nmem recall "project-scope" --depth 2 (project-specific)
  ↓
✨ CONTINUE SEAMLESSLY!
  User has full context from previous conversation!
```

## 💡 Key Features

### 1. Token Counting
```typescript
const autoSaveCheck = shouldAutoSaveConversation(chatMessages, systemPromptSize);
// Returns: { shouldSave, isCritical, currentTokens, percentage }
```

Conservative estimation: ~3 characters per token (works for EN/VN mix)

### 2. Project Scope Detection
```typescript
const projectScope = await extractProjectScope(dyadAppPath);
// Returns: "git:user/repo" or "path:project-name"
```

Tries git remote first, falls back to directory name.

### 3. Conversation Summary
Extracts from messages:
- **Key Decisions**: "decided", "decision", "chose", "selected"
- **Errors/Fixes**: "error", "bug", "fix", "solved", "resolved"
- **Features**: "implemented", "created", "added", "built", "feature"

### 4. Selective Memory Storage
- Top 10 decisions → `--type decision --priority 8`
- Top 10 errors → `--type error --priority 7`
- Project summary → `--type project --priority 9`
- Directory indexing → `nmem index`

### 5. User Notifications
Live updates during save:
```
🔔 Auto-Save Triggered
✅ Conversation saved to neural memory!
🚨 Critical threshold reached (95%)
```
