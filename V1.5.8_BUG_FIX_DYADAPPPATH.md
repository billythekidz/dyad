## 🔍 Root Cause Analysis

**File:** `src/ipc/handlers/chat_stream_handlers.ts`

**Problem:** Auto-save block (line ~1315-1350) uses `dyadAppPath` variable but it was never defined!

### Code Flow:

```typescript
// Line 1313: Auto-save check
const autoSaveCheck = shouldAutoSaveConversation(chatMessages, systemPromptSize);

if (autoSaveCheck.shouldSave && !req.skipAutoSave) {
  const percentage = autoSaveCheck.percentage.toFixed(1);
  logger.warn(`[AutoSave] ⚠️ Conversation at ${percentage}%...`);

  // Line 1322: ❌ BUG - dyadAppPath used but NOT defined!
  const projectScope = await extractProjectScope(dyadAppPath); // ❌ ERROR!

  // Line 1334: ❌ Used again
  const saved = await saveConversationToMemory(
    chatMessages,
    projectScope,
    dyadAppPath // ❌ ERROR!
  );
}
```

### Why This Happened:

**Other code blocks had it correctly defined:**

1. **Auto-inject context block (line 470):**
   ```typescript
   const dyadAppPath = getDyadAppPath(chat.app.path); ✅
   ```

2. **Manual save handler (line 2531):**
   ```typescript
   const dyadAppPath = getDyadAppPath(chat.app.path); ✅
   ```

3. **Auto-save block (line 1322):**
   ```typescript
   // ❌ MISSING! dyadAppPath not defined!
   const projectScope = await extractProjectScope(dyadAppPath);
   ```

**We forgot to add it when implementing auto-save (v1.5.6)!**

---

## ✅ The Fix

**File:** `src/ipc/handlers/chat_stream_handlers.ts`

**Line 1315-1322:**

### Before (BROKEN):
```typescript
if (autoSaveCheck.shouldSave && !req.skipAutoSave) {
  const percentage = autoSaveCheck.percentage.toFixed(1);
  logger.warn(
    `[AutoSave] ⚠️ Conversation at ${percentage}% of token limit...`
  );

  // Get project scope
  const projectScope = await extractProjectScope(dyadAppPath); // ❌ ERROR!
```

### After (FIXED):
```typescript
if (autoSaveCheck.shouldSave && !req.skipAutoSave) {
  const percentage = autoSaveCheck.percentage.toFixed(1);
  logger.warn(
    `[AutoSave] ⚠️ Conversation at ${percentage}% of token limit...`
  );

  // Get project path and scope
  const dyadAppPath = getDyadAppPath(updatedChat.app.path); // ✅ ADDED!
  const projectScope = await extractProjectScope(dyadAppPath);
```

**Change:** Added `const dyadAppPath = getDyadAppPath(updatedChat.app.path);` before using it.
