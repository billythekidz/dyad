# Neural Memory: User Guide

## Overview

Neural Memory is Dyad's intelligent conversation management system that enables **unlimited conversation length** while maintaining fast performance and low API costs.

## How It Works

Traditional chat systems send your entire conversation history with every message. This becomes slow and expensive in long conversations. Neural Memory solves this with a smart three-tier system:

```
┌─────────────────────────────────────┐
│         Your Conversation           │
├─────────────────────────────────────┤
│                                     │
│  🔥 Active Window (Recent 30-50)   │ ← Always included
│     Most recent messages            │
│                                     │
├─────────────────────────────────────┤
│                                     │
│  🧠 Recalled Context (Relevant)    │ ← Retrieved when needed
│     Semantically similar messages   │
│                                     │
├─────────────────────────────────────┤
│                                     │
│  📦 Summarized (Compressed)        │ ← Condensed summaries
│     Older conversation blocks       │
│                                     │
└─────────────────────────────────────┘
```

### The Three Tiers

1. **Active Window** (🔥 Hot)
   - Your most recent 30-50 messages
   - Always available instantly
   - Provides immediate context

2. **Recalled Context** (🧠 Semantic)
   - Relevant messages from earlier in the conversation
   - Retrieved using AI-powered semantic search
   - Only fetched when needed

3. **Summarized** (📦 Cold)
   - Automatic summaries created every 50 messages
   - Compressed view of older conversation
   - Keeps token usage low

## FAQ

### Q: Do I need to do anything to enable it?

A: No! Neural memory works automatically. Just start chatting.

### Q: Will it work with my existing conversations?

A: Yes! When you open an old conversation, it's automatically migrated to neural memory.

### Q: Can I see what's in each tier?

A: Yes, you can view:
- Active window: Most recent messages (visible in chat)
- Summaries: Click "View summaries" in the chat
- Recalled context: Shown when AI retrieves past messages

### Q: How do summaries work?

A: Every 50 messages, neural memory automatically creates a concise summary. These summaries are:
- Generated by AI
- Stored locally
- Used to provide big-picture context
- Viewable anytime

### Q: What if the AI forgets something?

A: Neural memory uses semantic search to recall relevant information. If you reference something from earlier, the AI will automatically retrieve it. You can also:
- Manually reference specific messages
- Ask the AI to "recall our earlier discussion about X"
- View summaries to remind yourself

### Q: Is my data safe?

A: Yes! All data is stored locally on your machine. Neural memory uses:
- Local SQLite database (same as before)
- Local `nmem` CLI tool for semantic search
- No cloud storage

### Q: Does it work offline?

A: The neural memory system works offline for:
- Viewing past messages
- Browsing summaries
- Message storage

You still need internet for AI model requests (same as before).

### Q: Can I disable it?

A: Yes, set `NEURAL_MEMORY_ENABLED=false` in your environment. However, we recommend trying it first!

## Troubleshooting

### Issue: AI doesn't remember something

**Solution**:
1. Try being more specific in your reference
2. Check if the topic is in a summary
3. Manually scroll back and reference the specific message

### Issue: Performance feels slow

**Solution**:
1. Check your system resources (CPU, memory)
2. Verify `nmem` is installed and working
3. Clear cache: restart Dyad

### Issue: Migration failed for old chat

**Solution**:
1. Close and reopen the chat
2. Check logs for errors
3. Report to support if persistent
