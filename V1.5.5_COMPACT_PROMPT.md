**File:** `.env.example`


- **true**: Dùng COMPACT (recommended, prevents errors)
- **false**: Dùng FULL (verbose instructions)

### 3. Auto-Enforcement Disable
Khi dùng COMPACT, không inject thêm reminder vì đã ngắn gọn rồi.

**File:** `src/ipc/handlers/chat_stream_handlers.ts:1255`
```typescript

const shouldForceMemory = !USE_COMPACT && userMessageCount <= 2;
```

### 4. Conditional Prompt Selection
**File:** `src/prompts/system_prompt.ts:517-523`
```typescript

  ? `${BUILD_SYSTEM_PREFIX_COMPACT}...`
```

## 🔄 Switching Between FULL and COMPACT

### Use COMPACT (Default):
1. Copy `.env.example` to `.env`
2. Keep `USE_COMPACT_PROMPT=true`
3. No rebuild needed (already default!)

### Use FULL (If Needed):
1. Edit `.env`: Set `USE_COMPACT_PROMPT=false`
2. Rebuild:
   ```bash
   cd D:\GITHUB\dyad
   npm run build
   ```
3. Launch Dyad

**When to use FULL?**
- Debugging prompt behavior
- Teaching new users (more verbose)
- Prefer detailed instructions over token efficiency

**When to use COMPACT?**
- **DEFAULT** - use this!
- Prevents token limit errors
- Faster responses (less tokens to process)
- Still 95%+ functionality
